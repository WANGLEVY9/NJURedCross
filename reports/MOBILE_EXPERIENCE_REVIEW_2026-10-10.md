# 移动端交互体验检查（2026-10-10）

## 检查范围与方法

在生产网站 `https://www.njuredcross.cn` 的现有登录会话中，检查官网、会员中心和管理端。以浏览器实际 DOM 视口为准检查 320px、392px、520px 宽度，以及 320px、400px 高度的短屏场景。浏览器缩放会影响工具设置值，因此不能直接把工具输入的尺寸当作页面实际 CSS 尺寸。

本轮实际操作包括：

- 官网移动导航展开、页面跳转、首页服务入口、主题面板展开和关闭。
- 会员中心切换个人资料页、展开和退出院系下拉列表、查看修改密码表单。
- 献血车周日历、班次详情、报名确认前的信息展示和禁用状态。
- 后台底部模块导航、侧栏、账号菜单、工作区菜单、搜索框输入和弹层取消。

线上检查未提交报名、修改资料、审批业务、发送验证码或修改密码。资料值和账号标识不纳入报告。自动化回归使用内存合成服务，不连接生产数据库。

## 发现与修复

| 问题 | 实际影响 | 修复 |
| --- | --- | --- |
| 账号菜单打开后焦点留在触发按钮，方向键只更新高亮，还会选中禁用项 | 键盘与辅助技术感知的操作对象不一致 | 聚焦首个可操作项，跳过禁用项；方向键、Home、End 移动真实焦点；关闭时返回触发按钮 |
| 移动侧栏中的工作区菜单按一次 Escape 会连同导航一起关闭 | 无法逐层退出 | 将菜单 Escape 纳入共享快捷键栈并阻止同次事件继续传播 |
| 菜单定位读取入场动画缩放中的矩形 | 窄屏右侧出现轻微越界；长菜单缺少高度约束 | 使用布局尺寸定位，限制菜单宽高、允许内部滚动；窗口尺寸改变时关闭旧菜单 |
| 搜索弹窗仅显示 Esc 提示，缺少可触控的关闭按钮，未使用共享背景隔离 | 手机端取消不够明确，背景控件仍可被辅助技术访问 | 增加具名关闭按钮，接入共享弹层、背景 inert、滚动锁定和焦点恢复 |

完整合成浏览器回归另外发现弹窗初始聚焦的时序竞争：快速切换字段时，延迟聚焦可能将输入带回第一项。现已在延迟回调中检查当前焦点，若焦点已进入弹窗则不再移动；新增确定性回归验证第二项保持焦点及输入值。此项来自合成回归，并非生产写入测试。

## 验证与证据边界

新增回归覆盖账号菜单焦点与禁用项、320px 窄屏边界、导航与菜单逐层退出、长菜单短屏滚动、搜索面板触控关闭与背景隔离。本地 `npm run verify` 通过（含 303 项 Node 测试及权限、身份、资料回归）；完整浏览器套件 62/62 通过，覆盖桌面与移动 Chromium；部署接收器的 6 项 Python 测试通过。

生产验收应同时核对 main 的 CI/部署结果、部署接收程序输出的发布 SHA 与文件校验回执，并重新加载线上页面复测上述修复。部署回执由服务器校验发布清单和运行文件、写入发布记录后输出；它不等同于人工 SSH 检查。

本轮设备证据为 Chromium 浏览器视口模拟与自动化移动配置，不代表已在实体 iPhone、Android 或 Safari 上验收，也不验证真实软键盘、系统返回手势或弱网表现。密码、报名和审批等写入业务未在生产提交测试数据。
