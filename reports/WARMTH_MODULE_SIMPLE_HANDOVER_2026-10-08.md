# 温暖连接生日祝福模块说明

> 更新日期：2026-10-08  


## 一、概括

暂时确定的逻辑是：

> 同学自愿加入生日祝福计划，写下祝福并提交审核；审核通过后进入祝福库，在收件人生日当天按规则送达。

完整闭环：

```text
加入计划 -> 提交祝福 -> 人工审核 -> 审核通过入库
-> 生日当天投递 -> 收件人查看 -> 举报处理 -> 拉黑或退出
```

当前进展：

| 部分 | 状态 | 说明 |
| --- | --- | --- |
| 公众端 | 已实现 | 加入、投稿、查看进度、修改重提、收件、举报、退出 |
| 管理端 | 已实现 | 审核、祝福库、举报处理、匹配预览、成员管理、拉黑 |
| 自动投递 | 已实现 | 生日当天按投稿额度和祝福池自动匹配并送达 |
| 规则保护 | 已实现 | 投稿上限、审核闸门、仓库唯一性、投递幂等、操作锁 |
| 操作留痕 | 已实现 | 加入、投稿、审核、投递、举报和拉黑均有审计 |

## 二、暂定的逻辑假设

1. **加入计划才可以取得参与资格**：没有加入计划，不能投稿，也不能进入收件候选。
2. **祝福分类**：投稿祝福可分为“随机匹配”（只用一次）与“加入祝福库”（多次复用）两类
3. **祝福限额**：每个账号限写三条祝福
4. **投稿需要被审核**：新投稿先进入“待审核”，审核通过后才写入祝福库。
5. **祝福库后台可见**：公众端不能浏览完整祝福库，只能看到已经投递给自己账号的祝福。
6. **投递量取决于本人通过审核的投稿数**：每有一条通过的“随机匹配”或“祝福仓库”投稿，才换取一条一对一祝福。


## 三、运行逻辑

### 1. 加入计划

- 成员登录后自愿加入生日祝福计划。
- 填写生日月日和校区。
- 加入后即时生效，不需要管理员确认。
- 可以随时修改生日资料或退出计划。

### 2. 提交祝福

- 用户填写对外昵称、祝福正文和投递方式。
- 投递方式只有“随机匹配”和“祝福仓库”。
- 投稿后统一进入“待审核”，不会直接参与投递。

### 3. 管理员审核

- 管理员可以作出“通过、需修改、直接拒绝”的决定。
- “需修改”的投稿由成员修改后重新进入审核。
- “已拒绝”的投稿可以由管理员撤销拒绝后重新审核。
- 只有“已通过”的投稿会进入祝福库。

### 4. 生成祝福池

- “随机匹配”投稿进入一对一随机池。
- “祝福仓库”投稿进入可重复调用的祝福仓库池。
- 已经随机投递过的祝福会转为“一对一已发过的”分类。
- 被举报撤下或作者删除的祝福会退出后续投递。

### 5. 生日当天投递

- 系统每天北京时间 08:00 检查当天过生日的成员。
- 先排除自己写的祝福和已经被匹配使用的随机祝福。
- 按收件人已经通过的“随机匹配 + 祝福仓库”数量生成一对一祝福。
- 随机池不足时，用祝福仓库补足差额。
- **该用户完全没有有效投稿时，仅从祝福仓库随机获得一条**。
- 投递结果写入站内记录，邮件作为并行通知通道。

### 6. 收件与举报

- 收件人只能查看投递给自己的祝福。
- 收件人可以看到祝福正文、署名昵称和写信人校区。
- 收件人可以对已送达祝福举报并填写理由。
- 管理员受理举报后，该祝福从后续投递池撤下。
- 已经送达的副本仍保留在收件记录中。

### 7. 退出与拉黑

- 成员可以主动退出，退出后不再进入投递队列。
- 管理员可以踢出或拉黑成员。
- 拉黑后禁止重新加入和投稿。
- 解除拉黑时，只恢复因拉黑产生的退出，不覆盖成员主动退出的选择。

## 四、核心规则

| 规则 | 当前设定 |
| --- | --- |
| 投稿资格 | 必须先加入生日祝福计划 |
| 投稿上限 | 每个账号最多保留 3 条进行中或已通过的投稿 |
| 祝福仓库限制 | 每人最多一条 |
| 已拒绝投稿 | 不占额度，可以重新撰写 |
| 审核结果 | 通过、需修改、直接拒绝 |
| 入库条件 | 只有审核通过才写入祝福库 |
| 收件数量 | 每条通过的随机匹配或祝福仓库投稿换取一条一对一祝福 |
| 无有效投稿 | 从祝福仓库随机获得一条 |
| 排除规则 | 不向本人投递其自己写的祝福 |
| 重复保护 | 同一条祝福不会在相同年份和日期重复投递给同一人 |
| 举报受理 | 祝福退出后续投递池，已送达副本保留 |
| 拉黑 | 同时踢出计划，并阻止重新加入和投稿 |

## 五、已实现功能

### 公众端

- 加入、修改和退出生日祝福计划。
- 生日月日选择与校区选择。
- 提交、修改、重新提交和删除祝福。
- 查看投稿状态与审核意见。
- 查看“我写过的祝福”和“我收到的祝福”。
- 查看祝福信件、署名昵称和写信人校区。
- 举报已收到的祝福并确认处理结果。
- 生日当天收到站内提示。
- 查看自己送出的祝福及对方昵称。

### 管理端

- 查看正常成员、已退出成员和黑名单成员。
- 查看成员资料和温暖连接统计。
- 审核投稿：通过、退回修改、直接拒绝、撤销拒绝。
- 浏览和检索祝福库。
- 查看匹配预览和预计投递数量。
- 处理举报并修改已处理结果。
- 踢出、拉黑和解除拉黑。
- 手动触发指定日期的生日投递。

### 系统能力

- 投稿上限和祝福仓库唯一性控制。
- 跨任务操作锁与投递幂等控制。
- 账号级限流和输入校验。
- 完整操作审计。
- 生日祝福核心链路自动化测试。
- 温暖连接页面渲染态无障碍审计。
