# 方块卡片与目录布局升级

以参考图的目录式布局和瀑布流布局为基础，统一用户端与管理端的视觉组件。浏览页面采用按行阅读的卡片网格；管理工作台保留两列分组、不同高度的面板，不打乱审批和表格的阅读顺序。

- 新增共享 cube.css，覆盖卡片、面板、统计、表单、按钮、列表、抽屉、导航和表格容器。保留十套主题的独立配色与状态色。
- 首页改为浅色主卡片和四个统计方块；五个广场入口采用目录网格；活动页从长条改为卡片目录，手机上纵向排列。
- 管理端工作台采用错落分栏面板，活动中心统一列表、详情和流程节点的圆角与留白。
- 手机按钮和输入控件提高触控尺寸，表格保留内部滚动。保留键盘焦点及减少动态效果设置。
- 首页保留统计加载占位，移除隐藏背景上的视差事件处理。

## 验证范围

`npm run verify` 通过：241 项回归。浏览器查看桌面首页、手机活动列表、管理端活动中心、新建活动抽屉。手机页面宽度扫描包括宣传、内建、物资、会员、管理活动/物资/宣传/连接/设置；测试文档没有横向溢出。最窄活动中心实测 CSS 宽度 320px，主内容宽度与滚动宽度均为 315px。

五种管理主题切换均保留正确强调色和卡片圆角，切回瓷白朱红。此轮使用隔离的合成管理预览及只读公开活动快照；预览不提供所有业务接口，因此窄屏外框检查不等于全部页面真实业务验收。没有向正式表写入测试活动。
