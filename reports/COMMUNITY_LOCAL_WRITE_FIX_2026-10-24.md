# 生日祝福本地写入修复

本地演示中，加入生日祝福计划约 30 秒后返回 409。读取模拟器的锁记录发现，其元数据把文本形式的 ISO 时间推断为 `date`，SeaTable SDK 将 `过期时间` 转为 `2026-10-24`，导致刚创建的租约立即被判定过期。

新增 `scripts/local-community-column-types.mjs`，使本地模拟器的早安晚安和生日字段类型服从现有 Schema；生产业务及其他模块代码保持原样。本地私有运行器已接入该类型函数，并在重启前备份、恢复全部 33 张模拟表。

验证：

- 安装的 SeaTable SDK 回归：原错误日期类型截断时间；修复后完整毫秒时间保留，租约仍有效。
- 生日加入返回 201（23ms），祝福投稿返回 201（26ms），本人投稿回读返回 200、状态为待审核。
- 使用本地 `local-member` 合成账号留下 1 条标有“本地演示验证”的待审核祝福，供管理端查看。
- 定向 Node 测试、lint、导入检查通过。

配置、凭据和模拟数据保存在 Git 忽略的本地私有目录中；真实服务地址仍为 `http://127.0.0.1:3300`，生产表及真实邮件未使用。
