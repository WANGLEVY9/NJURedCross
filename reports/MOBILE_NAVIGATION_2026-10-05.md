# 移动端导航与视觉适配

## 本次调整

志愿者端增加持续可见的五个广场底部入口，详情和表单路由继续归属对应广场。管理端增加工作台、物资中心、活动中心及全部模块入口，常用模块随当前账号权限过滤。全部模块沿用现有导航抽屉和焦点约束。

移动端统一较克制的方形卡片、轻边框与平面背景，减少渐变和阴影。精简管理端顶部按钮，预留底栏和设备安全区空间，保持表单字号与点击尺寸。桌面端不显示底栏。

修复延迟权限检查覆盖新路由的竞态；页面内容即时替换后再进入动画，避免旧退场动画覆盖新页面。新页面直接回到顶部，不再缓慢滚动。

## 验证

`npm run verify` 通过：项目检查、ESLint、权限契约、103 项身份验证、28 项个人资料验证及 86 项 Node 回归测试。新增回归覆盖迟到的路由 guard（重定向/允许两种结果）及无需等待退场动画的视图切换。

Chrome 视口检查覆盖 320×740、390×844、844×390 及默认桌面宽度。五个广场切换、管理常用入口、完整导航抽屉关闭与新建活动弹窗已验证。抽样页面没有整体横向溢出，管理正文底缘与底栏顶缘对齐。合成预览未提供的业务接口不能作为业务验收结果；未执行真实报名或审批。

尚需实际 iPhone / Android 验证软键盘、触摸及安全区表现。

## 技能安装

已有 `frontend-design` 保留；新安装 `responsive-design`（wshobson/agents）、`mobile-native` 和 `emil-design-eng`（emilkowalski/skills）、`ui-craft`（educlopez/ui-craft）、`high-end-visual-design`（leonxlnx/taste-skill 的 skills/soft-skill 目录）。技能来自用户指定仓库，安装为本地指令文件；本次主要采用响应式布局和 mobile-native 的适配规则。后续新会话可自动发现这些技能。
