# 内建广场与活动详情修复

根因：共享 program 卡片原为三列 grid，新样式只改变 flex-direction 而未改变 display，导致文字与按钮挤占列空间。内建页沿用三列目录配置，仅两张计划卡片被压窄。献血车页面使用未定义的 container/section 类，缺少居中容器。

修复：program 明确使用纵向 flex；内建专用两列卡片，手机单列，按钮置底。流程活动页面改用实际 formpage 容器，限定宽度并补齐边距。详情不重复输出整份通知，只展示工作内容和班次事实。私有报名接口返回对应公开活动标识，使详情能够显示当前班次的报名状态并过滤记录。已有报名显示状态和查看入口，不再重复显示报名按钮。请假和签到保留独立可展开区域；登录后返回原班次。

验证：241项回归通过，增加已有接口用例中活动标识映射断言。隔离预览检查两个计划加入抽屉、对应献血车报名状态、请假/签到展开；实测320px宽度下无横向溢出。不发送真实邮件、报名或签到。
