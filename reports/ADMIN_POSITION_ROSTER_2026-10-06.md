# 献血车管理员岗位名单入口修复

## 问题与实现

公开献血车班次详情此前只呈现本人报名及满额心愿清单，未接入已有管理员名单接口。现为具有活动模块权限的管理员及超级管理员增加“查看报名志愿者”折叠入口，按需读取 `/api/volunteer/workflow/events/:id/positions`，逐名额显示状态及已同步的志愿者资料。无资料的占用名额明确提示资料尚未同步。

服务端原有活动权限校验保持不变；公共活动接口和本人报名接口不增加他人身份信息。名单自动刷新后保持展开状态，支持手动刷新。该修复不修改真实报名记录，也未发送邮件。

## 验证

- `npm run verify` 通过，111 项 Node 回归及权限、身份、个人资料验证通过。
- 路由回归确认无活动管理权限时，在读取名单之前被拒绝；管理员和超级管理员授权请求可读取名单。
- 线上已满班次（2026-10-12 上午 10~14点，新街口印象汇）实际显示一个已占用名额，包含姓名、学号、邮箱及已同步的个人资料。证据检查只记录存在性，不保存报名者个人信息。
- 手动刷新班次后，名单保持展开并重新显示。
- 390 CSS 像素手机视口无横向溢出，名单卡片位于视口内。
- 未登录访问名单接口返回 401；公开页面冒烟 18 项通过。普通用户入口隐藏由角色回归验证，未借用真实普通用户账号登录。
