# 管理端加载优化与部署核验

日期：2026-10-04

## 排查与改动

| 页面或板块 | 原因与处理 |
| --- | --- |
| 活动中心 | 原先等待活动数据和整个源表目录。现在优先显示已有活动，源表目录后台读取；刷新保留当前内容。 |
| 物资中心 | 流水表原先在其他表之后读取，现在四张表并行读取。 |
| 志愿服务 | 大表通用分页由100行提高至500行；展示查询支持短时复用，减少重复读取。 |
| 宣传中心 | 项目、通知、审核、发布任务并行读取；未打开的标签页按需加载。 |
| 温暖连接 | 只加载当前标签页，已加载标签页保留结果。 |
| 系统设置 | 连接状态、操作记录按需加载；工作区偏好不触发无关查询。 |
| 工作台与通知 | 展示读取共享5秒快照；通知只读取当前账号有权限的模块。 |
| 数据中心 | 线上确认结构和数据预览正常；公共刷新组件保留已显示内容。 |

共享刷新组件还处理异步响应乱序，防止较慢的旧请求覆盖新结果。刷新失败保留已有内容并显示错误；认证失败清除旧内容。

展示快照按Base实例、表和选项隔离。认证查询、修改和业务核验不复用展示快照；成功修改后清除快照。
