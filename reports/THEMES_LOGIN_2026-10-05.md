# 平台主题与运营登录页

## 实现

- 运营登录页采用品牌介绍、四类业务插画与独立登录卡片；入场动效只运行一次，手机采用单栏布局。
- 活动平台与管理平台的外观选择分别覆盖其整个界面。页面顶部的「外观主题」按钮打开可即时预览的选择面板。
- 活动平台五套：晨曦红（纸感、浮起）、海风蓝（清透、方向引导）、青竹绿（柔和圆角、舒展）、鸢尾紫（柔光、焦点反馈）、秋日金（书页、安静线条）。
- 管理平台五套：瓷白朱红（清晰分区）、蓝图工坊（网格与方向引导）、竹影工作室（柔和圆角与层次）、紫雾画室（光影与焦点）、暖金书房（克制线条与衬线标题）。
- 调整背景、主色、按钮、选中态、卡片圆角、局部字体和悬停反馈。红十字品牌标识和业务状态色保持一致。
- 两个平台的主题及动效偏好独立保存在当前浏览器；刷新后恢复。存储不可用时仍可在当前页面预览。
- 提供交互动效开关；系统减少动态效果设置优先。关闭后停止 CSS 动画、JavaScript 动画、磁吸按钮及视差运动。

## 验证

- `npm run verify`：检查与 lint 通过，权限 26、身份 103、个人资料 28、Node 82，共 239 项通过。
- 浏览器逐一选择十套主题，核对主题标识；刷新后核对主题与动效选择，确认两个平台独立。
- 登录页、活动平台登录/主题面板及管理活动中心在手机布局下检查；实际 CSS 视口 433px，以及登录与主题面板 320px，无文档横向溢出。
- 对五种主色与白色按钮文字进行对比度测试，均达到 4.5:1。此项不等同于全站完整无障碍审计。
- 管理端活动中心的移动检查使用合成数据预览，无真实报名或审批写入。
