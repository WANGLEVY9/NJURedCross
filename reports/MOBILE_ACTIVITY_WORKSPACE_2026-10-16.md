# 移动端活动管理：现场任务工作区

## 范围与设计

本轮针对管理员手机操作，不复制桌面双栏工作台。使用项目本地 `frontend-design`、`emil-design-eng` 的渐进呈现、触控目标与功能优先原则；保持原生 ES Modules、共享组件和五套主题，无新增依赖。

沿用 console tokens：背景 `#f5f6f8`、纸面 `#ffffff`、浅底 `#eef0f3`、正文 `#20242b`、辅助文字 `#606975`、强调 `#c31f35`。实际 CSS 引用变量而非硬编码颜色。使用 NJU Sans；活动标题 21–22px，字段输入 16px，主要触控目标至少 44px。

```text
活动清单                     活动任务
搜索 / 状态                  返回清单       刷新
地区与类别（折叠）     →      活动身份 / 时间地点
活动 → 班次                  审批或班次 / 发布或设置 / 报名 / 签到 / 时长
管理工具（低频）              搜索志愿者 → 核验抽屉 → 明确确认
```

| 原先 | 本轮 | 原因 |
| --- | --- | --- |
| 目录与详情纵向叠放，多个滚动区域 | 手机同时只呈现清单或任务；目录自然滚动 | 减少寻找操作入口的滚动距离 |
| 首屏统计、配置、创建操作占据大面积 | 统计留在桌面，低频工具与地区类别折叠 | 优先活动选择和现场任务 |
| 同时出现五阶段与业务 Tab | 手机上隐藏重复流程条，保留短标签任务导航 | 保留业务门禁，降低导航负担 |
| 手机签到卡片内重复展开三项时长输入 | 从核验按钮进入现有签到与时长抽屉 | 先定位人，再核验和填写 |
| 桌面固定行高覆盖手机名单样式 | 手机卡片恢复内容自适应高度 | 消除不必要的留白 |
| 未定时长项目缺少签到搜索 | 姓名、学号、日期、时段搜索，批量选择仅限当前结果 | 便于现场找人且不误选隐藏记录 |

## 数据和保护

- 手机无活动深链接时只请求目录，选中活动后才读详情；保留详情缓存和项目—班次 ID。
- 保留 event、tab、scope、mode、area、category 等查询参数。返回清单移除 event/scope，刷新仍停留清单。
- 返回、切换和保存继续使用原有草稿保护；返回清单后到达的旧详情响应不会重新打开活动。
- 不变更审批、录用、请假、签到、时长审核、导出和邮件后端规则。名单确认与发送状态仍区分。
- 未定时长活动只核验签到，仍禁止计时和导出。批量签到仍须确认实际到场。
- 没有真实报名、签到、录用、邮件发送或底表迁移操作。浏览器写入测试仅运行在内存合成服务。
