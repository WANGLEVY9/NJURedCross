# 公共下拉框与献血车筛选栏优化

## 变更

采用 emil-design-eng 的对齐、动效与移动端原则，以及 mantine-combobox 的目标控件、选中标识、键盘及浮层交互原则。项目使用原生 JavaScript，因此实现共享 select-only combobox，未引入 React/Mantine 运行时。

所有下拉框均由 `field()` 创建；已统一接入主题化选择控件。原 select 保留表单值、校验、禁用和程序赋值接口，展示改为圆角触发器与顶层选项面板，支持方向键、Home/End、文字定位、Enter/Space、Esc、Tab、外部点击关闭及选中标记。较长选项列表可滚动；菜单根据可用空间向上或向下展开，跟随滚动定位。支持 reduced-motion，键盘展开无入场动画。不支持 Popover API 的旧浏览器保留原生选择框作为兼容回退。

献血车筛选栏 PC 同高底部对齐，手机分行后选择框与复选控件保持同高。通用输入框默认最小高度统一为 44px，会员资料选择框沿用 48px。打开筛选菜单时暂停日历自动刷新，防止选择过程被打断。

## 验证

- `npm run verify` 通过；111 项 Node 回归，以及权限、身份、会员资料验证通过。
- 独立浏览器交互夹具 `node scripts/preview-select.mjs`：必填返回无效并聚焦可见控件；程序赋值同步标签；FormData 输出正确值且不包括禁用控件；原生重置后标签恢复；30 项列表可用 End 选择最后一项；长菜单滚动且不越出手机视口。
- 合成活动中心：抽屉模板选择可展开，Esc 仅关闭选项菜单而保留抽屉。上述验证未写入正式数据库。
- 正式献血车日历：点位变更同步底层值且正确筛选班次；选择框与复选控件均约 44px，高度相同，底部差小于 1px；390 CSS 像素视口无横向溢出，菜单在视口内。
- 线上 18 项公开页面及接口冒烟通过，发布文件哈希与本地一致，服务 active。
