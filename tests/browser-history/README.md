# 旧活动管理页面测试存档

活动管理已按 `docs/ACTIVITY_WORKSPACE_V2_REQUIREMENTS.md` 整体重建，不兼容旧活动页面。这些测试要求旧活动树、抽屉、默认审核人配置、任意审核人选择、实时通知预览、旧名单筛选和直接停止报名，与当前需求冲突，因此不再属于当前浏览器测试集。保留原文件供历史核对，不通过恢复旧界面或跳过当前测试来满足旧断言。

当前入口、草稿、岗位、通知、复制、负责人资料、地区权限、审批发布、名单、签到初审、时长导出、删除和响应丢失核对由 `tests/browser/activity-draft-workspace-v2.spec.mjs` 验证。该文件在 Chromium 桌面和手机、Firefox、WebKit 中执行。它覆盖真实控制台路由及独立组件，使用合成服务和数据。

替代关系：

| 历史测试主题 | 当前验证 |
| --- | --- |
| 活动树、分类、手机任务、旧项目导航 | 固定筛选及双栏滚动、地区类别卡片、真实入口无跳转、单项目卡片与岗位强切换 |
| 创建表单、通知、复制、负责人 | 草稿保存与预览失效、岗位无默认值、所有岗位复制及通知更新、分管主任资料档案 |
| 默认审核人配置、选择审核人、审批、发布 | 本地区主席团审批、负责人只读、退回重提、立即或无预填定时发布及取消 |
| 名单与筛选、成功邮件编辑器 | 报名结果即时通知、批量选择、失败理由及失败重试、只读权限、截止条件 |
| 现场签到与时长、旧操作抽屉 | 可选签到证据、负责人初审、全部参与人导入、完整预览后提交、最终表格预览导出 |

旧接口的服务端权限、CSRF、重复请求和审计测试仍在 `tests/*.test.mjs` 执行。公众端活动、分组报名、认证、共享组件及其他管理模块浏览器测试仍在 `tests/browser` 执行。
