# 活动中心本地验收（2026-10-06）

本轮对应开发文档，重点为发布报名、名单确认。仅本地代码与内存合成数据；没有调用远程表格写入、变更远程结构、发送真实邮件或创建 MR。无需配置 API Token 即可运行 `npm run preview:workflow`，打开 http://127.0.0.1:3121/console/events。关闭预览进程后合成操作不保留。

## 可验收功能

- 五个步骤独立切换；名单确认只展示报名管理。原签到、请假、时长流程保留，录入表预览移至时长步骤。
- 默认“进行中”；活动中心分类按钮（已确认使用“综事类”）；名称、类别、日期、服务队的去空格多关键词搜索；筛选无匹配时清空旧详情。
- 新建活动顶部仅选择南京活动/苏州活动，移除模板描述和标题说明。活动信息依次为活动名称、空白手填的活动类别、负责人；移除活动中心/活动队选择与日期前缀功能。当前账号为第一负责人，可多选已有活动权限的管理员为补充负责人。编辑不覆盖第一负责人，编辑者仍受独立审批约束。
- 第二板块“活动安排”包含日期、合并的起止时段、地点、选填岗位、推荐录取名额、上限名额及活动内容。时段采用一组并排下拉框，仅提供 00:00–23:30 的整点/半点选项，自动计算服务时长。地点控件与其他字段对齐，填写示例使用框外小字。
- 第三板块“时长分配”包含培训、交通、服务时长与工作内容；培训/交通默认各 1 小时，服务时长随时段自动更新。
- 推荐录取人数与报名上限独立，对外只显示推荐名额。新表单明确保存上限，服务端串行控制并发报名；确认人数可超过推荐值，但不能超过上限。未设置上限的历史配置保留旧录取约束，编辑后可设置上限。
- “南大红会”标题通知模板，继承地点、时间与活动内容，提供默认福利和报名要求。发布页可直接编辑整篇正文，包括标题、时间、地点与链接；提供恢复预设模板、实时预览和复制当前正文。自定义正文不会被定时设置或后续活动配置编辑覆盖；修改通知仍需重新审批。
- 定时开始使用独立日期框和整点/半点时间下拉框，按显式北京时间（+08:00）保存；日期和时间须一起填写，可用“取消定时”清空。通知保存会清除审批，重新审批后点击“启动定时发布”。报名 API 和公开目录按持久化时间判断开放，不依赖浏览器计时器或后台写表任务，服务重启后仍有效。倒计时仅用于显示。
- 名单调整阶段按待确认/拟录取/拟不录取/全部切换；最终确认后显示报名成功/报名失败。筛选与排序分开，桌面紧凑表格、手机卡片，报名时间加粗深色。勾选仅更新行高亮和计数，不重建名单；排序保留选择，切换筛选清空选择。批量暂定只处理待确认人员。
- 拟录取和拟不录取均可直接撤销暂定，退回待确认；不发送邮件，不改变报名人看到的结果。未公布人员始终显示“名单确认中”，内部暂定原因不会出现在报名人接口。已有签到/时长证据或待审批请假时不能调整。最终名单需通过顶部“修改已确认名单”重新进入调整，原公布结果保留至下一次最终确认。
- 更多资料通过白名单显示业务档案，不返回密码、令牌或身份表原始行。证书从既有个人主页的“急救证”字段只读匹配；核心成员只认可明确的“红会核心成员”字段，未知显示“未提供”，不通过院系、部门或会员码推断。
- 移除勾选后发送及逐人补发入口。所有待确认和请假审批处理完成后，才可“最终确认并发送通知”。核对成功/失败人数后关闭新报名、统一公布并发送给成功和失败人员；已请假人员不纳入通知。发送分批显示进度，失败可重试，成功收据持久化，不因刷新或重试重复通知。名单再次确认时，只有结果/原因改变者生成新通知版本。
- 卡片调整阶段只显示暂定结果与“暂定 · 未通知”，最终确认后才显示邮件状态。全员发送成功时隐藏重试按钮，汇总通知完成数量。持久化使用现有报名页配置中的 rosterReview，审批摘要排除这一运行状态，活动业务配置仍受审批保护；不新增远程列。提交前冻结名单，中途失败可恢复，报名人不会看到部分提交结果；所有新写入 API 仍受权限、CSRF、来源校验、串行队列及审计约束，名单令牌阻止过期页面覆盖。SMTP 后收据写入失败时先核对已有发件记录，无可靠证据则显示待核对并停止自动重发。

## 仍需业务配置与确认

- 四位主席的账号及活动中心/服务队对应关系尚未提供，当前仍采用现有活动模块审批权限，未声称已完成主席专属审批路由；超级管理员能力保留。
- 补充负责人从已有活动权限管理员中选择，不修改账号全局权限；活动级权限收紧需结合主席及管理员实际组织关系决定。
- 未接真实数据源联调；证书原始值若不是明确的“有/无、是/否”等枚举，会显示原文并保持筛选状态未知，需确认实际枚举及核心成员字段。资料 Base 未配置时保留账号资料，证书/成员信息显示未提供。
- 没有最终报名链接，通知先引导平台活动中心；管理页提供当前活动报名页面。
- 定时功能为网站通知与报名入口开放，不向微信群或其他外部渠道自动发布。
