# 按活动类别分配审核主席

新提交的活动按现有组织类别唯一确定审核主席。当前类别包括苏州分部、主席团、一加助残、博爱中心、生命中心、综事中心和献血车专项；旧名称“苏州类、主席团类、博爱类、生命类、综事类”会转换为对应现有类别。地区、活动专项、补充负责人不参与审核人选择。

## 配置和使用

1. 超级管理员进入活动管理，点击“配置审核主席”，为各类别选择启用且有活动权限的管理员。一个账号可以负责多个类别。未配置类别允许保存草稿，不允许提交审批。
2. 创建者选择活动类别后看到“审核主席：姓名”。点击“提交审批”时，服务端从配置中确定稳定账号 ID，忽略请求中自行填写的审核人。
3. 对应主席在“待我审核”中查看所属类别的申请；所有启用的超级管理员拥有全部活动的审批权，“待我审核”显示所有待审核申请。对应主席或任意超级管理员选择“审批通过”或填写原因“退回修改”，任意一人通过即可，不是多人会签。其他普通管理员即使直接调用接口也不能审核。退回后变为草稿，原因显示在详情中。
4. 负责人修改后重新提交；类别、通知等需要审批的内容修改后旧批准失效，重新提交时按当前配置重新分配。通过后继续原发布报名流程。

保留现有普通负责人／最后修改者不能自行审批的约束和原有超级管理员自审例外；本轮不增加备用审核人流程。全局审批依据服务端最新账号的 `super_admin` 角色，不按姓名认定，也不接受请求中伪造的角色；停用或降级后立即失去全局审批权。实际审核人写入审批记录，退回原因记录实际处理者，而非原分配主席。如实际有三位超级管理员，每个活动通常是三位全局审核人加一位类别主席；同一账号重复时去重。

修改对应关系不会悄悄转交已提交申请，旧任务保留提交时的审核人；审核时仍检查该账号是否启用且有活动权限。如需更换待审核任务的审核人，先编辑为草稿，再重新提交。暂不提供额外转交按钮。

## 存储与上线

- 对应关系存储在服务器私有 JSON 文件，环境变量 `PLATFORM_ACTIVITY_APPROVERS_FILE` 指定路径，默认 `.activity-approvers.json`。保存采用版本冲突检测、进程内串行队列与临时文件原子替换。现有部署是单实例，不支持多实例共享此文件的并发写入。
- 文件及临时文件已加入 Git 忽略，不提交真实账号 ID。生产应指定可由服务账号写入、独立于发布目录且可持久备份的绝对路径。代码发布不携带真实配置，首次使用前需要超级管理员配置实际主席账号。
- 活动的分配快照、退回原因保存在现有“报名页配置”内，参与审批摘要。无需增加远程表列，不修改账号角色或权限配置；配置读取、修改与退回操作仍受活动权限、CSRF、同源校验与审计保护。
- 已发布／已批准的历史活动继续原流程。旧待审核申请没有分配快照时普通主席不能审核，需编辑并重新提交；超级管理员可直接审核或退回，不批量修改真实业务数据。自动生成的献血车班次继续现有来源规则，不强行对历史／来源已批准班次重新审批。
- `createWorkflow` 在完整服务器注入审核策略；未注入的独立旧测试夹具保持原审批契约。上线需配套部署前端与服务端。

## 本地演示与验证

`npm run preview:workflow` 只使用内存模拟数据。各类别初始配置名称明确、独立的模拟审核人，均不代表实际主席分工：`synthetic-reviewer`（模拟博爱主席）、`synthetic-second-chair`（模拟综事主席）、`synthetic-life-chair`（模拟生命主席）、`synthetic-presidium-chair`（模拟主席团审核人）、`synthetic-suzhou-chair`（模拟苏州主席）、`synthetic-disability-chair`（模拟一加助残审核人）、`synthetic-blood-chair`（模拟献血车审核人）。另有 `synthetic-organizer`（负责人）、`synthetic-super`（超级管理员）。预览登录不验证密码，不能用于正式环境。可在模拟超级管理员配置页选择“未配置”测试提交拒绝。配置和活动操作在预览进程重启后恢复。

行为测试 `tests/activity-approval.test.mjs` 覆盖缺少配置、类别别名、服务端指定权限、伪造审核人、配置变更、编辑后重新分配、退回／重提、停用与撤权、旧申请、配置越权、CSRF／同源、私有文件重启和并发冲突。浏览器测试 `tests/browser/activity-approval.spec.mjs` 覆盖桌面／手机选择类别、待我审核、跨主席拒绝、退回重提通过及配置入口。

本机可使用已安装的 Edge，无需下载 Chrome：`npx playwright test --config=playwright.edge.config.mjs tests/browser/activity-approval.spec.mjs`。该配置只改变测试浏览器，不限制网站用户使用其他浏览器。

## 回滚

保留私有配置备份后回滚配套代码。旧版本不识别新的类别审核约束；若仍有待审核申请，应暂停审核并核对已分配任务，避免恢复成所有活动管理员均可批准。已公布结果及真实业务操作不由代码回滚撤销。
