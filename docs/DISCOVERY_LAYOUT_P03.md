# P03：活动广场的稀疏数据布局

范围：第四轮 UI 审计第一轮 P03；仅修改活动目录，不改变活动分类、接口、缓存、权限或报名规则。

## 根因与取舍

实际测量发现 `.portal__outlet` 的 `min-height: calc(100svh - 76px)` 与活动页的 `min-height: calc(100svh - 200px)`、底部 32px padding 叠加；结果区另有 240px 最小高度。Footer 是 outlet 后的独立节点，内容较少时，空白被留在 outlet 内。

在 1920×1080、dawn 主题、相同合成数据下，结果区底部到 Footer 顶部的距离：

| 数据场景 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 0 项 | 260.6px | 48px |
| 1 项普通活动 | 280.2px | 48px |
| 3 项普通活动 | 166.0px | 48px |
| 10 项普通活动 | 80px | 48px |
| 1 项献血车聚合（2 个班次） | 251.0px | 48px |

选择“活动目录 + 相邻参与说明”方案，替代原本下置的宽三步条。单活动采用约 2.2:1 的主次结构；2–4 项使用全宽首条与双列目录组合（偶数为双列）；5 项以上保持扫描列表。顺序来自现有数据，没有增加推荐排序。0 项沿用真实空状态，无结果时提供筛选重置。

线框：标题与真实结果数 → 筛选区 → [单活动 | 三步说明] / [少量目录] / [长列表] → 48px 收尾 → Footer。

不采用强制拉高卡片或新增装饰填空。保留 P00 的标题边缘主题线稿，增加目录栏目编号。背景仍归 atmosphere.css 所有；本轮布局样式集中修改 discovery-art.css，删除重复的单卡规则。仅活动路由取消 outlet 的视口最小高度，其他页面保持原样。
