# 早安晚安模块

## 边界

早安晚安是独立于生日祝福的业务模块。

它可以复用平台的账号、会话、权限、CSRF、SeaTable、邮件、审计和通用 UI 组件，但不能复用生日祝福的参加表、投稿状态机、祝福库或投递规则。

模块自有代码优先放在：

- `lib/morning/`
- `public/app/portal/pages/morning*.js`
- `public/app/portal/morning-comments.js`
- `public/styles/morning.css`
- `tests/*morning*.test.mjs`
- `scripts/*morning*.mjs`

## 数据表

### `早安晚安名片表`

保存成员报名名片和审核结果。

关键字段：

- `名片ID`
- `账号ID`
- `真实姓名快照`
- `学号快照`
- `性别快照`
- `校区`
- `昵称`
- `兴趣标签`
- `备注`
- `允许评论邮件`
- `审核状态`
- `审核意见`
- `审核人`
- `审核时间`
- `提交时间`
- `发布时间`
- `更新时间`

状态：

- `待审核`
- `已发布`
- `需修改`
- `已拒绝`
- `已退出`
- `已删除`

### `早安晚安评论表`

保存成员对已发布名片的评论，以及邮件通知和联系方式公开选择。

字段：

- `评论ID`
- `名片ID`
- `评论人账号ID`
- `内容`
- `状态`
- `是否发邮件`
- `公开学号`
- `公开邮箱`
- `公开QQ`
- `公开微信`
- `创建时间`
- `更新时间`

## 报名与审核

报名时从账号资料读取真实姓名、学号、性别和邮箱。邮箱来自个人中心，是只读展示；真实姓名、学号、性别用于审核核验，不进入广场公开投影。

成员可选择是否允许别人通过评论邮件通知自己。关闭后评论仍会保存，但不会向名片主人发送评论邮件。

管理员审核页：

```text
/console/community/morning
```

控制台接口：

```text
GET  /api/community/morning/cards
GET  /api/community/morning/cards/:id
POST /api/community/morning/cards/:id/review
```

审核列表默认只显示 `待审核` 名片，支持按审核状态和关键词筛选。只有 `待审核` 名片可以提交通过、退回或拒绝；通过后写入发布时间并进入广场，退回和拒绝必须填写审核意见。

状态流转：

```text
待审核 -> 已发布
待审核 -> 需修改
待审核 -> 已拒绝
需修改/已拒绝 -> 待审核（成员重新提交）
待审核/已发布/需修改/已拒绝 -> 已退出（成员主动退出）
```

## 广场与详情

广场入口：

- `/morning/plaza`

广场只展示当前账号以外的 `已发布` 名片。列表返回备注摘要；长备注需要打开详情弹窗查看完整内容。

详情投影只包含：

- 名片 ID
- 昵称
- 校区
- 兴趣标签
- 备注
- 是否允许评论邮件
- 发布时间

详情不展示真实姓名、学号、邮箱、联系方式或账号 ID。

## 评论与邮件

评论接口：

```text
GET  /api/morning/cards/:id/comments
POST /api/morning/cards/:id/comments
```

评论正文会公开显示在名片详情下。

发表评论时可以选择：

- 是否向名片主人发送邮件
- 邮件里是否附上自己的学号
- 邮件里是否附上自己的邮箱
- 邮件里是否附上自己的 QQ
- 邮件里是否附上自己的微信

学号和邮箱从个人中心读取，前端只读展示，后端始终以当前登录账号为准。QQ 和微信默认从个人中心读取，也可以在评论表单中补充或临时修改。

如果名片主人关闭了“允许评论邮件”，评论仍会发布，但不会发送邮件。

邮件幂等键：

```text
MORNING-COMMENT:<评论ID>
```

## 并发保护

`lib/morning/shared.js` 提供统一的 `withMorningCardLock(accountId, task)`。

以下操作必须使用同一个账号级锁：

- 成员提交/重新提交名片
- 成员退出计划
- 管理员审核名片

这样可以避免“用户退出后又被审核写回已发布”或同一账号并发创建多张有效名片。
