# 首页品牌舞台与五专题插画

第二轮对应美术手册 P02 / P03 / P06。默认使用 Warm Editorial Canvas：保留第一轮方向性光场，标题与专题各占桌面约一半宽度，最大版心 1480px。Impact Ribbon 横跨两列，连接近期活动；各项来自现有活动/统计 API，读取失败不伪造数字，缺失值显示破折号。

## 插画与入口

`hero-showcase.js` 从 `PORTAL_NAV` 取得五个入口、名称、描述和顺序，补充同源专题文案。首页项目卡片使用同一份专题配置。五份原创 SVG 均为 640×480，使用外部 SVG use 引用与主题变量，无外部图片请求、第三方版权素材或虚构业务数据。

| 专题 | 构图 | 路径 |
| --- | --- | --- |
| 参与·行动 | 错层日期卡、确认笔画、太阳与行动轨迹 | /events |
| 记录·表达 | 双层刊物、图像框与裁切标记 | /outreach |
| 连接·关怀 | 交织纽带、信封与月相 | /community |
| 准备·支持 | 叠放储物盒、分类签与配送方向 | /materials |
| 积累·成长 | 个人档案、阶梯路径与里程碑 | /me |

图形本身不含真实活动、库存或成就。SVG 的主色、次色、纸面和墨色随五主题更新；正式徽标保持不变。项目卡片沿用不对称 5/4/3 + 6/6 栅格，活动卡深色，宣传卡浅纸面，内建卡柔色，底部两卡使用横向插画。卡片悬停仅移动图形 3px 和改变边线，整卡不跳动。

## 动态与可访问性

默认第一张为活动广场，7 秒自动切换，进入动画 420ms，仅 opacity/transform。显式播放/暂停按钮；悬停、焦点进入和页面隐藏暂停，手动切页后持续暂停，需主动播放才恢复。系统或产品减少动态时关闭计时器，手动切换仍可使用。

五个选择按钮、前后方向按钮和当前序号常驻，不因切页重建焦点。方向键只在控制区有效；按钮原生支持 Enter/Space。非当前幻灯片使用 hidden，不进入 Tab 顺序或无障碍树；自动播放不播报，手动选择通过单独 polite 状态区域播报。CTA 为独立链接；会员入口继续使用既有登录守卫。

dispose 清理 timeout、AbortController 管理的监听器和 MutationObserver。外观主题变化不重新创建轮播，不请求业务 API，不丢失当前页。

## A/B 比较与样式所有权

`home-page[data-art-direction="spotlight"]` 是局部 Chromatic Spotlight 对照方案，仅右侧艺术舞台使用主题深色，页面其余部分保持浅纸面。实际浏览器输出两套同尺寸截图；默认 A，因其能保持公益内容的亲近感，避免深色面板争夺主标题权重。B 不作为新的用户主题 ID。

`discovery-art.css` 保留 Hero 光场、标题、Impact Ribbon 与业务列表；删除原 hero-art 的静态单图规则。`hero-showcase.css` 负责专题结构、控制器、进入动画、卡片插画位置与对照方向。无运行时依赖，无 CSP 放宽。

## 验证范围

本地 workflow preview 使用合成数据：五主题 × 五专题 × 1440/1920 截图；导航、键盘、暂停、页面隐藏、dispose、减少动态与 forced-colors 回归。主入口卡的正文与底色检查 AA 4.5:1。通用测试另覆盖 1280/390/320 布局。线上验收只读取公开页面，不提交业务数据。
