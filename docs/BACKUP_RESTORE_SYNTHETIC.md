# 私有状态的合成备份恢复演练

## 范围

演练仅使用临时目录、合成凭据、测试密钥、example.test 邮箱和生成图片。
不读取 .env，不访问 SeaTable 或 SMTP，不操作真实状态目录。

执行：

~~~powershell
node --test tests/sqlite-backup-restore.test.mjs tests/private-files-backup-restore.test.mjs
~~~

当前共 10 个测试。临时数据在测试结束后清理。

## 已验证内容

| 对象 | 恢复验证 |
| --- | --- |
| SQLite 快照 | 包含已提交 WAL 数据，排除未提交事务；恢复后完整性检查通过 |
| 快照目标 | 非空目标不会被覆盖 |
| 物资凭据 | 未完成阶段、固定计划及申请和资产的未完成查询保持一致 |
| 审计凭据 | 加密内容与未确认状态保持一致；错误密钥或 Base UUID 拒绝打开 |
| 邮件发送状态 | unknown 与 sent 保持原状态，未确认留痕状态不丢失，不允许直接回到 sending |
| 邮件重试队列 | 正文可用原密钥解密；尝试次数、到期时间和下次尝试时间保持一致 |
| 会话撤销文件 | 旧会话仍被撤销，原到期时间不因恢复延长，文件不保存原始 CSRF 值 |
| 照片文件 | 原始字节与校验清单一致；缺失或修改后能够检测差异 |

SQLite 测试使用 VACUUM INTO 生成单个数据库的一致性快照，
随后恢复到新的临时文件，并使用实际领域存储模块读取。

照片清单只比较 UUID 命名文件的大小和 SHA-256。
测试中图片在复制期间没有变化，不构成在线照片目录的原子快照。

## 尚未验证的边界

- 多个数据库、会话文件、照片及 SeaTable 之间的共同时间点一致性。
- 生产备份权限、加密存放、异地传输、保留周期和恢复耗时。
- 断电、磁盘损坏、空间不足和备份过程被中断。
- 目标服务器操作系统与 Node 版本下的执行结果。
- 已恢复状态与远端业务写入或 SMTP 实际投递结果的核对。

合成演练通过不代表生产备份恢复已验收。
不得将本测试中的快照函数直接当作生产备份工具。

## 真实恢复前要求

维护者须明确恢复目标、备份时间、密钥和 Base 配置，
停止相关服务、后台任务及维护写入脚本，
并先在隔离目录验证备份，不能覆盖当前状态库直接试验。

恢复旧快照会回退本地记录，但不会撤销快照之后发生的远端写入、
邮件投递或会话操作。需要核对远端结果，并评估快照之后的退出撤销记录。

恢复后不能仅凭本地缺少凭据认定远端未执行，
不能清空状态来解除业务阻断或强制重发邮件。
