# 本地物资 API 只读查看器

此查看器独立于合成数据预览，直接读取物资管理试验板的表结构和记录，不加载账号库、通知服务，不执行初始化或写入。

用户于 2026-10-07 确认：后续开发以这个 API 的真实物资数据为读取来源，开发阶段不得修改远端库中的数据或结构。新增、修改、删除、库存操作与审核均只在本地模拟，不向远端同步。项目约束见 [AGENTS.md](../AGENTS.md)。

仅连接 UUID 为 `c707b1ab-ac5c-46b3-9d77-1bc4ea16f241` 的物资试验板，并读取项目使用的四张表：工位物资表、物资配置表、物资流水表、物资管理。不使用志愿服务平台或敏感信息存储的凭据。

本地配置文件 `.env.materials-local` 已由 `.env.*` 规则忽略。配置字段为 `MATERIALS_READONLY_SERVER`、`MATERIALS_READONLY_BASE_UUID`、`MATERIALS_READONLY_TOKEN`、`MATERIALS_READONLY_PORT`。凭据仅供后端使用，不加入 Git、网页或响应。当前服务地址限制为 `https://table.nju.edu.cn`，若地址发生变化须先核实并修改适配器的来源限制。

运行 `npm run preview:materials:source`，访问 `http://127.0.0.1:3123/`。页面按原始字段展示，每页最多 100 条，支持翻页及展开 JSON。页面使用文本节点渲染数据，不执行表格中的 HTML，也不自动请求附件地址。

服务器仅监听本机地址，所有非 GET 请求返回 405。认证结果必须与指定 UUID 一致，才会读取表格。缺表、连接失败和非 JSON 响应会明确显示，不回退到合成数据。

2026-10-07 最新复查：认证、四张表结构与记录读取均成功，之前的 HTTP 500 未再出现。默认业务开发命令 `npm run preview:materials` 已通过完整分页载入工位物资表 140 条、物资配置表 100 条、物资流水表 0 条、物资管理 33 条的本地内存副本。本页仍逐次读取远端，是独立的只读对照入口；每页 100 条不代表总数。完整快照读取检查缺表、记录编号重复及容量超限，失败不回退到合成数据。现有借用历史缺少出库流水时保留核查提示，编码与跨品类申请协议仍需对齐。
