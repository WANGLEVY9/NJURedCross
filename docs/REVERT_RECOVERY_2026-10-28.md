## NJUTable 读取与当前活动管理的适配

- 恢复身份、资料关联、验证码及社区子表的限定字段查询；有 SQL 能力时不因查询报错静默退回整表扫描。
- 保留当前活动管理按活动 ID 读取报名、签到、时长明细，以及按报名行 ID 获取核验资料的实现。
- 恢复有上限的并发分页，用于确实需要全目录的完整读取；并发数可用 `PLATFORM_PAGED_READ_CONCURRENCY` 设置为 1–16，默认 8。
- 恢复展示缓存的有限旧值窗口与后台刷新。会话改变和写入使客户端缓存失效；服务端按表失效，鉴权和写入不使用展示旧值。
- 保留当前角色名单 provider 的账号快照与文件实时读取策略，不重新引入另一套全局账号缓存。

新增 `tests/recovery-read-boundaries.test.mjs` 验证当前活动报名读取确实带活动 ID 条件、不调用整表接口，写入路径绕过展示缓存，以及写入后旧后台结果不能覆盖新缓存。
