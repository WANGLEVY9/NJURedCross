# 温暖连接作者邮件提醒

提醒发到作者账号登记的邮箱，不使用请求体传入的邮箱或名片中自行填写的联系方式。

- 生日祝福通过、需修改、拒绝或撤销拒绝重新待审后，给作者发送状态和审核意见；重新审核通过会收到新一轮结果。
- 早安晚安首次名片审核和已发布名片的资料修订审核，通过、退回修改或拒绝后均通知作者。审核失败、权限不足、重复审核不会触发通知。
- 每份随机匹配或仓库祝福形成成功站内投递记录后提醒作者；仓库同一投稿送给不同收件人时分别提醒。“写给挚友”仅在 SMTP 已确认或幂等记录证实发出后提醒。

提醒只包含投稿编号、投递日期/方式，或审核意见及本人查看入口；不透露随机收件人的姓名、学号或邮箱。提醒不撤销已完成的审核/祝福投递；缺少作者邮箱时不猜测其他联系方式。

提醒使用独立的 `community-notification` 邮件类型，首次发送前复用现有加密重试库保存通知正文；发送前可确认未发出的失败按现有退避策略重试，发送结果不明确时沿用原有停止自动重发机制。审核事件和投递记录各自拥有稳定幂等键，重复投递扫描不会重复发作者提醒。普通生日投递扫描只恢复当前投递日期的通知，不批量补发历史提醒。

无需新增 SeaTable 表、字段、依赖或环境变量。真实邮件需要原有 SMTP、私有邮件状态目录与邮件重试任务正常运行。未配置 SMTP 时，生产环境不会发送真实邮件。开发与测试均使用合成账号和模拟发送函数，不向真实成员发测试邮件。
