# 前端设计系统与交互约定

实现参考。规范性的美术方向、样式归属与尺度见 [DESIGN.md](../DESIGN.md)；运行与模块组织见 [前端 README](../public/README.md)；扩展动效、断点和组件预览见 [.impeccable/design.json](../.impeccable/design.json)。

## 前端架构

无构建工具、无外部运行时依赖，直接以原生 ES Module 提供服务；服务端 CSP 为 `script-src 'self'; style-src 'self'`，因此代码中**不存在内联样式与内联脚本**，所有动态样式都通过 CSSOM（`style.setProperty`）或 SVG 表现属性写入。

```text

  assets/                   品牌标记与噪点纹理
  styles/

    themes.css              十套调色板的语义覆盖
    base.css                Reset、字体层级原语、环境视觉层
    components.css          共享组件层
```

### 设计系统要点

- **令牌先行**：共享颜色、字体、间距（4px 基数）、圆角、层级与动效时长以 `tokens.css` 为基础，`themes.css` 提供主题覆盖；日历文字、班次基础色、阴影及局部排版位于 `calendar.css`，环境光位于 `atmosphere.css`，首页和活动广场局部文字、阴影及排版位于 `discovery-art.css`。公众端与管理端沿用各自主题偏好和同名语义变量。
- **克制的主色**：主色承担关键操作、Focus、Active、数据高亮及随主题变化的背景光场；页面结构主要依靠排版、留白、分隔线与表面层次建立。
- **状态三重表达**：所有状态同时使用颜色、文字与图标（必要时加脉冲动效），不依赖颜色单独传达信息。
- **Card 不是默认容器**：只有具备独立语义、状态与交互时才使用面板；其余用 `wsregion` / `section-head` / 分隔线 / 表面层建立结构。
- **完整状态覆盖**：每个数据区域都实现 default / loading（骨架屏）/ empty（含主操作）/ error（原因 + 重试 + 技术细节）。

### 交互与动效

- **命令面板**：`⌘K` / `Ctrl K`（`/` 亦可）打开，支持模糊搜索、分组、最近使用与键盘导航；命令源由当前外壳注册，因此始终与当前界面能力一致。
- **快捷键**：`⌘K` 搜索 · `⌘I` 通知中心 · `⌘B` 折叠导航 · `⌘⇧D` 切换信息密度 · `Esc` 关闭当前面板／Inspector · `↑↓` 列表导航 · `Enter` 确认。快捷键可枚举，并在 Tooltip 与系统设置中展示。
- **Inspector 优先**：在列表中选中对象时右侧滑出详情，而不是跳转页面；窄屏自动改为覆盖式面板。
- **Drawer / Sheet / Modal 分工**：上下文创建与编辑用抽屉（窄屏自动降级为底部 Sheet），仅不可逆确认使用模态（支持输入短语二次确认）。
- **上下文菜单**：列表行支持右键菜单，动作按对象状态启用或禁用。
- **Motion System**：`transform` / `opacity` 驱动，共享时长为 90–620ms；日历筛选重绘为 220ms，全局背景无运动；包含页面淡入位移、FLIP 布局过渡（筛选与排序）、共享元素扩展（活动卡片 → 详情）、Spring 抽屉与开关、磁吸主按钮、面板 Spotlight 跟随、Hero 视差与数字滚动计数。全部遵循 `prefers-reduced-motion`。
- **写入前预览**：入库/出库/归还/盘点先显示 `18 → 15` 形式的库存变化与阈值影响；报名先说明「直接确认」或「候补第 N 位」。
- **结果凭证**：写入成功后返回业务编号、时间、操作摘要与后续动作；报名与代报名额外返回可下载的签到二维码。

### 数据可视化

图表全部为自研 SVG，不使用图表库默认皮肤：坐标轴与网格刻意弱化，数据承担视觉重量，支持十字准线、交互 Tooltip、图例开关与入场动画。趋势曲线只使用真实事件（活动报名/签到/取消、物资出入库流水）按 Asia/Shanghai 逐日聚合；没有事件时显示空状态而不是伪造曲线。

## 页面约定

### 日历与班次

- 预约工作区最大宽度为 1480px；日历内部保留月份/周导航与筛选，页面几何由 `booking.css` 统一管理，`calendar.css` 仅管理周日历。
- 桌面保持七列周视图，700px 及以下仅展示选中日期的班次；摘要始终统计整周筛选结果。
- 桌面提供「舒展/紧凑」密度，班次最小高度分别为 164px / 125px，选择保存在传入的日历状态对象中；700px 及以下单日布局不受桌面密度影响。
- 日期左右方向键在当前周内移动，Home/End 选择周首/周末，到边界停止；选中状态与焦点同步。
- 选择班次后立即滚动并聚焦详情容器；「返回日历」恢复选中班次焦点，若该班次不存在或不可见则恢复选中日期焦点。
- 点位与「仅看有名额」可组合，无结果时区分无排班和已满，重置保留当前周。筛选自动选择有匹配班次的日期，保留日期焦点与传入状态。
- 班次按点位、时间、名额、状态呈现，满额为中性浅灰虚线，可报名为浅绿，个人待审核/确认分别为暖黄与浅蓝；今日下划线、选中日期灰蓝底、周末文字独立表达。

### 首页与活动发现

- 首页与活动广场内容最大宽度为 1480px。首页桌面双列主视觉、原创海报与真实统计；760px 及以下主视觉单列，五个服务入口按宽度收至两列、单列。
- 1181px 起共享门户页头高 76px，导航项高 44px，当前页保留主题浅底、文字和下划线；滚动 12px 后切换为实色表面和轻阴影，过渡 160ms。
- 全平台背景由 `atmosphere.css` 按当前页面根类分配：主页暖纸、活动低噪、日历/会员中性工作底色、宣传象牙、内建暖纸。首页深蓝主视觉、白色服务章节和砂色页脚归 `discovery-art.css`。
- 首页统计保留现有 API 口径：开放活动数与剩余名额加大，累计参与与物资品类作为次级指标，0 值照实显示；概览失败显示「暂未更新」，不伪装为零。
- 近期活动与活动广场复用活动行组件：最多六项，桌面双列、手机单列，单项横向展开；空态提供真实下一步。献血车聚合为一个入口，与普通活动统一日期块、日期／地点／安排三行及报名操作，日期、点位名称、班次数和名额来自真实记录。
- 活动广场展示搜索、状态、分类和校区的已选条件，支持单项清除与全部重置并同步 URL；清除状态或分类后聚焦对应分段，清除搜索、校区或重置全部后聚焦搜索框。结果通过 polite、atomic 状态区域宣告。键盘输入跳过列表 FLIP，指针输入恢复。
- 减少透明度偏好使服务面板、统计条和广场标题变为纯白。

### 报名与结果

- 报名资料采用参与者身份签：姓名与章节标题使用 NJU Serif，账号信息采用 NJU Sans；标签和值统一行高并按基线对齐。勾选框对齐确认文字首行，状态反馈与提交门禁保留。
- 心愿清单沿用内建的信笺语言，以心形邮票、书签和信封空态区分关注内容；卡片展示班次日期与地点，查看入口按普通活动／献血车类型返回对应页面。
- 普通活动采用日期导航、场馆分组、两行班次选项；日期切换更新详情与 URL 并保留键盘焦点。已报名与当前选中独立表达，不推测报名资格。
- 确认区桌面左侧突出时间、地点和参与安排，右侧为只读身份与报名操作；1000px 以下按任务顺序堆叠。标题用 NJU Serif，正文 16px，班次时间 20px，状态 13–14px；不新增字体或运行时依赖。
- 须知未确认时按钮具有实色禁用外观。提交期间阻止刷新干扰，以服务器返回结果区分成功与待审核；结果不确定时保留提示并禁止本页重复提交，后续查询到记录后恢复真实状态。提交成功但后续刷新失败不宣称报名失败。
- 记录复用 `registrationPresentation()`，默认紧凑展示事实与进度，原生 Disclosure 按资格提供取消/请假和签到。刷新保留仍被允许的操作中的原因草稿、待上传文件、展开状态与焦点；操作成功后清除对应输入。上传完成不等于签到已核验。
- 心愿清单采用低强调度信笺；空态提供返回班次入口，始终说明提醒不预留名额。五个主题均使用现有语义色与主题令牌。
