# 管理端通知收件邮箱

管理人员在会员中心「个人资料」填写「收信邮箱」，即可使用常用邮箱接收业务通知；留空或格式无效时回退原邮箱。注册验证、找回密码和审核权限仍使用原身份邮箱。

- 活动审批、发布及活动待办汇总已使用统一 `mailRecipient`。
- 宣传待办汇总按对接人表原邮箱唯一匹配平台账号，使用该账号当前收信邮箱。只对投递所用的副本进行映射，不改对接人表及审核鉴权所用邮箱，不凭姓名或收信邮箱推断账号。
- 报销审核人与申请人通知均使用账号收信邮箱；原有账号 ID、审核人姓名、启用状态及邮箱验证检查保留。
- 宣传与活动待办仍按实际投递地址合并；发送时段维持北京时间 08:00、20:00。

每次汇总共享一次最新账号读取，通过统一 `content/read` 观测；账号读取失败或超时时延后该次汇总，不以陈旧地址继续投递。宣传对接人匹配到多个账号，或唯一账号已停用、未验证时不猜收件人；未关联平台账号的既有对接地址保持原配置。

验证覆盖常用邮箱优先、留空及无效地址回退、地址变更、重复账号、停用和未验证账号、审核身份不变，以及活动宣传合并后实际投递地址。测试仅使用合成数据及替身发送函数，不发送真实邮件。
