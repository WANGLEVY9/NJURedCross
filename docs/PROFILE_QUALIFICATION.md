# 急救证填写与培训状态同步

会员中心沿用个人主页底表已有的“急救证”列，只显示一个必填下拉框，与校区字段使用同一组件。已有资料自动带出，未登记需主动选择；没有证书可选“否”。不新增底表列、不修改选项或自动化设置。部门和时长仍按既有管理边界维护。

保存通过现有姓名、学号、已验证邮箱及唯一绑定核对，并复用资料三方合并和持久待重试机制。兼容底表历史 CPR 选项名称，写入时使用底表已有选项名称。旧版本遗留的证书声明仅迁移一次，不作为新的用户修改回写。新填写和底表的并发修改均保留，不自动覆盖。

顶部完整性提示与报名接口使用同一个必填规则，报名时读取底表当前急救证值。保存同步成功且所有必填资料有效后不再显示缺失提醒。未同步成功时保留输入并提示待处理，不将本地填写当作已完成底表写入。

资料冲突按字段提供说明；只有身份匹配、唯一性或绑定校验失败才显示身份冲突说明。不会向用户返回其他人的资料。

## 一加培训自动更新

- 仅识别活动名称同时明确出现“一加”和“急救”的活动。
- 仅处理终审通过且有正时长的最终归档记录，报名审核、初审、未通过和零时长记录不触发。
- 匹配个人主页底表的唯一姓名和学号；只有当前明确选择“否”时，改为底表已有的“否，但参加过一加急救培训”对应选项。
- 已有一加培训、CPR、AHA 或未知/空白状态不改写。不会授予 CPR/AHA 证书，也不降级已有资质。
- 与会员资料同步共用进程内写入队列，元数据读取后再次核对最新资质；重复执行不重复更新。
- 使用现有时长同步任务执行，成功回执保存在独立同步状态中。失败显示资质更新待重试；重试不重复累计时长。
- 只修改急救证列。时长仍写两张汇总表，个人主页时长由 NJUTable 自动化维护。
