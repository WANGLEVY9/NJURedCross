# P01 / P02 首页品牌舞台与栏目编排

本轮按第四轮审计的 P01 → P02 实施。保留原生 JavaScript/CSS、正式徽标、五专题插画、真实活动接口与统计口径。

## 设计审计与方案

原首页右侧轮播是一块独立纸色卡片，标题、背景轴与统计之间联系弱；下方依次出现相似底色区块，信任说明只占一行。现有自动轮播、暂停、键盘、减少动态和卸载清理均已实现，本轮不重复建立交互系统。

借鉴用户提供的纸艺分层参考，使用原创 SVG 曲线，表达“行动与回应”的相互连接。没有复制参考图片、添加人物照片或虚构公益数据。

- A：浅色编辑舞台，右侧深度有限，但更安静。
- B：仅右侧局部深色纸面，叠加主题副色、浅纸层，轮播内容始终使用独立可读表面。
- 实际比较 1920×1080 截图后采用 B。A 保留为 `data-art-direction="editorial"` 比较状态；生产为 `spotlight`。深色不到全屏，不随每次轮播换色。

晨曦红采用既有画布 #f7f1eb、纸面 #fffaf5、墨色 #462d35、艺术强调 #6e233b、辅色 #ead1c5 / #e6d7ad；其余四主题全部引用对应语义 token。字体沿用 NJU Serif 展示标题、NJU Sans 正文与控件。未增加字体资源。

## 实现与所有权

- `home-paper.js`：五个静态路径组成原创分层背景。无 filter、视差、持续动画；不接收输入且对辅助技术隐藏。
- `atmosphere.css`：纸层位置、主题色与栏目底材；取消首页旧的通用页面装饰，避免重复底板。
- `page-art.js`：首页由独立纸艺场景管理，其他页面继续使用原背景。
- `home.js`：Hero 舞台、近期活动栏目、三项真实参与说明。
- `hero-showcase.css`：可读舞台、稳定脚注高度、服务卡统一内基线；取消服务插画悬浮位移。
- `discovery-art.css`：Hero/数字带/近期活动间距、单献血车 CTA 回到左侧、信任区结构。

单献血车：左侧名称、名额和入口，右侧实际日期/点位/班次数。多个活动：保持现有顺序和目录链接；0 项继续真实空状态。五张服务卡保留原 SVG 及 2+3 等宽排列，不增加卡片。
