# 活动管理重建：用户确认需求

本文件以用户后续修订为准；作为实现和验收依据，不等同于所有条目已完成。2026-10-20 起，旧活动通过统一工作区内的兼容适配层继续管理；原记录与业务状态不迁移、不改写。

## 页面框架

- 保留管理端公共导航，各页面导航宽度保持一致；活动目录收窄，卡片圆角。
- 不显示顶部活动统计、服务记录核对跳转、“配置 · 审批 · 参与管理”等说明。
- 搜索下方一排三个下拉：阶段、地区、类别。阶段默认全部，其余六项为草稿、待审批、报名中、进行中、时长审核、已结束。
- 地区和类别强绑定，使用原代码完整名称：主席团专项、博爱中心、生命中心、综事中心、排班专项；南京另有一加助残专项、献血车专项。
- 左侧活动卡片和右侧操作内容各自滚动，必要时表格内部横向滚动，其余框架固定。收起目录仅用小箭头。
- 右侧顶部是活动名称和六阶段进度，下面是统一工具栏，再下面是当前阶段完整操作盘面；不跳到另一个活动工作区，不把六个阶段混为多套操作页。
- 工具栏先放活动信息查看、活动信息修改，再放阶段操作，更多操作靠最右；按钮醒目，禁用时变灰且不可操作，不能直接删除修改按钮。
- 标签到输入框、输入框内文字、按钮内文字、控件之间的间距统一，避免大块无效留白。页面不出现解释实现方式的文案。
- 不显示草稿创建人或测试审核人；不显示清除筛选按钮，筛选通过选回全部恢复；下拉箭头居中。

## 地区及角色

- 南京、苏州主席团分别处理本地区活动；组织名称相同，不能据名称猜地区。角色、地区、中心和有效人员名单由服务端绑定。
- 负责人从所属地区、分管中心的主任中选择，通过稳定账号关联个人资料档案；不重复选择负责人。
- 分管负责主任可在提交审批前编辑；所属地区主席团可在活动开始前编辑。其他中心、校区或未获权限人员只能按权限查看，不能写入。
- 时长初审由本项目负责主任完成，终审由所属地区主席团完成，两轮不可混淆。

## 新建与草稿

- 新建位置不变，弹窗必填活动名称、地区和类别（地区类别联动），然后直接打开同一工作区的草稿编辑。目录卡片只显示名称和状态，类别以颜色区分，地区以边框样式区分，不另加分类文字。
- 岗位数量下拉为待选择、单岗位、多岗位；无默认值，主动选择后才展开其余内容，不再称为报名方式。
- 单岗位沿用统一报名安排；多岗位完整配置每岗名称、日期、当天具体起止时刻、地点、内容、人数及服务/培训/交通时长。
- 活动可以跨多日；岗位具体日期和时刻必须保留。
- 同一页面连续填写，不分步骤，不展示实时预览；通知随信息和岗位自动整合生成，手写内容须避免被悄悄覆盖。
- 通知采用活动招募文案结构，不按数据库字段堆叠。多岗位的工作、具体时间、地点、人数及时长统一置于工作内容下，按岗位逐条整理；不编造报名要求、群号或额外福利。
- 特殊操作：保存草稿、预览、提交审批。提交必须先保存并预览最新版本。

## 待审批

- 除所属地区主席团外均只读，主要展示审批进度和活动信息预览。
- 主席团可修改保存、审批通过、审批退回；退回需原因，回到同一活动草稿。
- 审批通过后弹出发布选择：立即发布或定时发布。定时不预填，须主动选择有效未来时间。
- 发布仅由所属地区主席团处理。关闭弹窗保留已批准未发布状态；实际发布前仍属于待审批。

## 报名中

- 岗位使用名称强切换，单岗位不显示多岗位切换条；报名状态仍使用下拉。右侧小字显示概览。
- 表格仅显示姓名、学号、校区、岗位及时间、报名状态，保护其余个人资料。
- 结果无默认值，主动判定成功或失败，可批量处理；每次结果直接触发可靠邮件通知，不设独立“报名结果通知”操作。
- 默认无勾选框，仅显示批量操作按钮。进入批量模式后才显示勾选框、选择数量及成功/失败动作，退出后收起；无选择当前筛选结果、清除选择或刷新名单按钮，保留表头全选框。
- 失败原因必填，默认“很遗憾的通知您，您报名的活动已满”，可修改。
- 满额自动阻止新增报名，显示“报名中 · 报名已满”，仍须手动截止，不直接进入进行中。
- 主任和所属地区主席团均可直接截止，无需再次审批；截止前整个项目所有人必须已有成功/失败结果。

## 进行中

- 特殊操作为上传时长表。名单显示姓名、学号、时长、签到查看和主任初审通过/不通过。
- 岗位强切换、审核状态筛选及概览保持统一，写权限为本项目负责主任。
- 单岗位不显示岗位切换栏；无刷新名单按钮。负责人初审采用下拉选择审核通过/不通过，不通过须填写情况；已有签到图片可查看，签到链接可选填，没有签到附件不阻止审核，不自动创造签到记录。
- 上传后提交审核前必须在独立浮层完整预览，右下角提交或取消。
- 更多操作提供回退报名中入口，需检查时间、报名截止、签到、时长和已保存初审等状态，不能破坏现有记录。

## 时长审核与已结束

- 特殊操作合并为预览并导出；完整分工时长表用大浮层展示，不限于右侧窄区域。浮层右下角为导出，返回用右上角关闭按钮；负责人只读预览时导出禁用。
- 按用户参考表格式生成，可直接修改工作明细；相关预览与时长数据同步，人员身份仍绑定档案。
- 正式工作日期保留岗位具体日期与起止时刻，跨日显示两端日期；实际交通时间不得凭总小时数猜测。
- 导出后进入已结束，给负责人发送最终表附件和录入时长提醒；同一文件保留网页下载。
- 已结束仍可查看活动信息，负责人及所属地区主席团可以下载最终表。

## 更多操作

- 复制为新活动：新建独立草稿卡片，复制基本信息及完整岗位配置，重建岗位标识与通知；不复制审批、报名、签到、时长。
- 发布前删除，发布后提前结束，均为软移除，任务目录不再显示但保留业务备份；不能与正常导出完成混淆。
- 写入须由服务端核对权限与最新版本，不明确的响应应核对原请求，不能通过重复写入猜结果。
