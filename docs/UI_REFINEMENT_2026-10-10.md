# 全站界面精修记录（2026-10-10）

本轮以 main 的 `d00617b` 为基线，在独立检出中实施。保留原生 JavaScript/CSS、主题偏好、共享组件、路由与业务接口。

## 设计方向

沿用红会品牌，官网首屏使用现有深红背景与浅色正文，主体仍采用当前主题的浅色表面。品牌色 `#d8283f`、深红 `#a3132a`、首屏底色 `#160c10`、首屏正文 `#fff6f4`、辅助正文 `#e0cbd0` 构成主要视觉关系。公共表面继续由语义颜色变量决定，不覆盖用户选择的主题。

中文正文和业务数据保留项目系统字体栈。官网标题有明显层级；后台标题固定字号，数字使用等宽数字特性。布局以左对齐、内容分组、一致的间距和必要的分隔线表达结构。

| 范围 | Before | After |
| --- | --- | --- |
| 官网首屏 | 宽屏信息集中左侧，首屏偏高 | 双栏展示核心说明和三项常用服务，窄屏自然堆叠 |
| 服务入口 | 第一个入口占两列，视觉权重不均 | 同类服务采用一致的布局与卡片尺度 |

| 弹层 | 依赖局部 Tab 陷阱，底层仍可参与交互 | 背景和非顶层弹层 inert 隔离，重复关闭幂等，关闭后恢复焦点 |
| 页面切换 | 触发元素移除后焦点落到 body | 焦点丢失时转到主内容区，保留页面显式输入焦点 |

## 实现组织

`public/styles/experience.css` 为本轮跨表面精修层，最后加载，复用现有语义颜色、共享组件类和主题偏好。功能专用样式继续由各自模块维护。后续调整同类规则应在这一层合并，避免添加重复覆盖文件。

行为修改集中于共享 overlay、table 和主渲染流程；首页常用服务使用原有真实路由。未加入 React、GSAP 或其他运行时库。无数据库、权限或接口契约变更。

## 使用的 Skills

- frontend-design：明确品牌、排版层级和服务导向的布局。
- Impeccable polish / operate：检查既有系统、跨表面一致性和交互完整性；机械扫描无发现，仍需浏览器验收。
- emil-design-eng：聚焦操作反馈、可中断动效和键盘体验。
- UI/UX Pro Max：用于设计知识检索。首轮结果偏向作品集，与校园公益平台不符；针对 nonprofit volunteer 的检索亦无匹配，因此未套用其推荐配色和布局，采用实际项目设计系统作为依据。

## 验证与边界

`npm run verify` 覆盖模块与文档检查、ESLint、权限/账号回归及 Node 单元测试。`npm run test:browser` 使用内存合成服务，覆盖桌面与手机、公开路由、管理端导航、活动周切换、登录跳转、嵌套弹层、首页服务入口和表格键盘交互。

浏览器用例对首页提供明确的合成活动与统计数据，同时既有测试继续检查接口未覆盖时的降级页面。测试不连接生产 NJUTable 或 SMTP，不产生真实报名或管理写入。视觉验收包含桌面、手机和减少动态效果。真实邮件投递及生产业务写入不属于本次 UI 回归的验证结论。

发布采用既有 main CI/CD；以 Actions 部署回执、服务器 release.json 的文件校验结果和公开页面资源哈希为上线依据。推送本身不代表已部署。
