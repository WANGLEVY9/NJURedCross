# 审核工作流运维手册（v3）

> 适用版本：NJU RedCross 平台 v3（分支 `feature/v3-changes`）
> 面向对象：宣传中心对接人、审核人、运营同学
> 最后更新：2026-10-11

本文讲**怎么用**，不讲怎么开发。开发细节见 `PLATFORM_ARCHITECTURE.md` §4A。

---

## 1. 一图看懂：内容从投稿到发布

```
投稿人提交
   │
   ▼
① 对接人初审 ──退回（附检查清单 + 修改意见 Word）──▶ 投稿人修改后重新提交
   │ 通过                       （同一层最多退回一次）
   ▼
② 审核人终审 ──退回（同上）
   │ 通过
   ▼
③ 末级通过 → 「已通过 · 待排期」
   │
   ▼
④ 创建排期任务（选渠道 + 发布形式 + 计划时间）
   │  平台只写「待人工发布」任务，绝不自动对外发送
   ▼
⑤ 人工在对应渠道发布 → 回平台「登记结果」（已发布 / 发布失败）
```

> **每一级的「通过」都要求**：逐项打勾确认 21 项检查清单（勾 = 该项已确认合格）。
> 缺项无法通过；若确有问题，改选「退回修改」并填写意见。

## 2. 三级审核链（按投稿类型自动匹配）

| 投稿类型 | 级数 | 第一级 | 第二级 | 第三级 |
| --- | --- | --- | --- | --- |
| **文字稿件**（article） | 2 级 | 对接人初审（含美编招募） | 审核人终审 | — |
| **文创设计**（design） | 3 级 | 草稿/线稿定稿 | 上色铺色 | 成稿终审 |
| **小绿书**（brief） | 2 级 | 对接人初审 | 审核人终审 | — |

> 小绿书与文字稿件同构（N3-a 用户确认），篇幅短、以图文卡片为主。

**对接人 / 审核人按栏目自动匹配**，在审核抽屉里随栏目切换实时刷新。分工表见
`宣传对接人表`（10 条分工 seed）；未指派时沿用账号邮箱。

## 3. 审核操作与规则（重要）

**在哪里审**：控制台 `/console/outreach` → 页签「**内容看板**」→ 点**卡片** → 详情底部「开始审核」。
（「公众投稿」页签点行也会打开同一套审核抽屉，两个入口走的是**同一条审核链**，不会出现状态不一致。）

1. **清单必填（勾 = 该项已确认合格）**：每次提交审核（通过或退回）都要过一遍 21 项检查清单。
   - **通过**时**必须逐项打勾确认全部 21 项**，缺项会报错「还有 N 项检查项未确认合格」，无法提交；
   - **退回**时不强制打勾，但勾了的项会随意见一起留存，便于投稿人对照修改。
   - **界面（v3.2 改版）**：清单按 8 个类别分组展示，头部有「已确认 n/N」计数与进度条（全部勾满时计数与进度条变绿）；
     每组标题右侧有分组计数（如「内容 3/5」）；勾选一项 = 方框填实打勾 + 行底色高亮 + 行尾出现「已确认」标签，
     三重信号不依赖单一颜色；「全部确认 / 清空」按钮可批量操作。
2. **同一级最多退回一次**：该级已经退回过的，「退回修改」会被拒绝（提示仅可提一轮）。
3. **退回必须填审核意见**（留空会报错）。
4. **修改意见（选填）**：可逐条填写「位置 / 问题描述 / 修改要求」，条数不限。
5. **生成《审核意见》Word**：点抽屉左下角「生成意见 Word」→ 文件**下载到浏览器下载目录**
   （文件名 `审核意见-<标题>.docx`），含稿件信息 + 清单勾选结果 + 修改意见表，可直接回传投稿人。
   > 注意：该 Word 是**本地下载**，**不会**自动归档进 SeaTable；如需留档请自行存入云盘。
6. **逐级推进**：文字稿件/小绿书 2 级、文创设计 3 级，每级都要"清单勾满 + 通过"才算过。
   末级通过后看板卡片进入「已通过 · 待排期」，此时才能创建排期任务。

### 3.1 审核检查清单（21 项 · 8 类）

对应《南京大学红十字会公众号美编审核清单》，逐字数字化，存 `审核清单模板表`（可按需增删，控制台自动读取）。

| 类别 | 检查项（标准） |
| --- | --- |
| **内容** | 错别字/语病（通读无错别字、无病句、无歧义）· 知识点与逻辑（专业无误，前后不矛盾，结构完整）· 事实要素（人名、职务、机构、时间、数据准确）· 立意与导向（弘扬主旋律，无商业推广与不当表述）· 原创性（真实原创，贴合红十字精神，无抄袭） |
| **表述** | 红十字标识（白底红十字，未变形、改色或作装饰）· 红十字精神（表述为"人道、博爱、奉献"）· 机构名称（使用全称或规范简称，不生造） |
| **隐私** | 服务对象照片（已打码至无法辨认身份）· 帮扶对象（无真实姓名、班级、住址、联系方式）· 团队成员照片（团队成员不打码，已确认出镜同意） |
| **图片** | 清晰度与水印（实拍为主，清晰无重影、无水印）· 图片版权（使用他人图片已取得授权或标明来源） |
| **格式** | 标题（（栏目分类）\| 标题）· 署名（文编／美编／责编齐全）· 结尾（来源标注、尾图（二维码）到位） |
| **排版** | 段落与空行（段首不空格、两端对齐；段与段、图与文空行）· 图片与注释（图间不空行、图文间空行，注释居中）· 配色与夜间（色系相近、总颜色≤3种；夜间模式预览正常） |
| **后台** | 封面（封面图已完善） |
| **发布** | 发布预览（回看预览，链接、图片、排版正常） |

## 4. 发布形式与排期门禁

- 排期时**必须选发布形式**：`大推文` / `小绿书`（写入任务便于统计）。
- **门禁**：审核链未走完就创建排期 → 返回 **409**（提示"请先完成审核"）。
- 排期只创建「待人工发布」任务；`发布结果登记` 里勾选"我理解平台不会自动对外发送"才能提交。
- 发布失败可**重新登记**（记录失败原因），支持多次重试计数。

> **名词澄清**：本节说的「排期任务」是**投稿的发布排期**（挂在该篇投稿上，控制台「发布排期」页签）。
> 它和成员侧 `/tasks` 的**「任务表（心愿清单）」是两回事**——后者是宣传中心对外招募
> （摄影/排版/设计等），发布要带「技能要求」，成员申领后需管理员在「任务审核」页签通过才算接单。
> 详见 [任务与技能](TASKS_AND_SKILLS.md)。

## 5. 常见问题（FAQ）

**Q：投稿人看不到我的意见？**
A：审核意见存在服务端记录 + 《审核意见》Word。回传 Word 或口头告知即可；
平台不自动发邮件给投稿人（可后续接入）。

**Q：为什么点「通过」提交不了，提示"还有 N 项检查项未确认合格"？**
A：清单必填——通过前必须逐项打勾确认全部 21 项。确有问题时改选「退回修改」，
退回不强制勾满，但请把有问题的项勾上并填写修改意见。

**Q：为什么"退回修改"提交时报错？**
A：两种情况：① 该级别本轮已经退回过一次（按制度仅可提一轮，需管理员特批）；
② 没填审核意见（退回必须写明意见）。等投稿人改完重新提交即可再次退回。

**Q：我自己审自己的稿子行不行？**
A：可以（平台不硬拦），但建议按对接人/审核人分工表走，留痕更清晰。

**Q：文创设计为什么是 3 级？**
A：设计稿分「线稿定稿 → 上色 → 成稿终审」三步，与文字稿的两级不同。

**Q：历史稿件（v3 之前提交的）怎么审？**
A：整条链都走同一套多级审核；v3 之前已标记"已通过"但没有审核层级/轨迹的存量稿件，
按"已终审"兼容处理，不会被新规则拦住排期。

**Q：「内容看板」和「公众投稿」两个地方都能审，有什么区别？**
A：没有区别——两个入口打开的是**同一套**审核抽屉、走同一条审核链、写同一批字段。
推荐用「内容看板」（有六列流水视图，更直观）。

**Q：宣传展示里的文章从哪来？**
A：控制台「宣传展示」页粘贴公众号链接一键导入（详见第 6 节）。

## 6. 宣传展示维护（半自动导入）

> **不再需要本地 .exe 脚本**——网页端一键完成。

1. 进 控制台 →「宣传展示」。
2. 在「公众号文章链接」框里**每行粘一条**链接（单次最多 30 条）。
3. 选**展示分类**：直接选公众号 11 栏目之一（小红帮推 / 活动预热 / 活动总结 / 健康小蓝鲸 / 今日节日 / 心灵慢车 / 南男女侣 / 红会新闻 / 南小红月报 / 人道法言 / 红会招新），与投稿「推文栏目」同一份字典，展示墙按它分节。
   抓取被公众号反爬拦下时（线上服务器在境外，微信只回「环境异常」页），用面板底部「抓不到？手动补一条」：填标题 + 封面图地址即可照样入库。
4. 可选：勾选「同时抓取正文全文图」。
5. 点「提取并导入」→ 逐条回显：
   - ✅ 成功（含封面 / 正文图张数）
   - ❌ 失败（带原因，**绝不静默**）
   - ⏭️ 已存在跳过（按「标题 + 链接」查重，不产生重复行）
6. 下方列表管理：**改栏目 / 排序 / 上下架 / 删除条目**（删除条目**不删** Box 封面文件）。

### 6.1 抓取失败怎么办？

公众号对机房 IP 会返回「环境异常」占位页（无 `og:title`）。此时平台会明确提示
**「公众号反爬拦截，请在微信内打开验证」**。处理办法：

1. 在**手机微信**里打开该文章；
2. 用文章的「复制链接」拿到**带参数的完整链接**（`https://mp.weixin.qq.com/s/xxx?__biz=...`）再试；
3. 仍不行 → 走**手动导入**：把标题、链接填进 `showcase.json`（见 `scripts/README.md`），
   或直接用控制台列表的编辑功能手工建条目。

## 7. 权限与安全速查

| 动作 | 需要什么 |
| --- | --- |
| 看控制台「宣传中心 / 宣传展示」 | 账号有 `outreach` 权限 |
| 审核 / 排期 / 导入 / 删除条目 | 登录 + CSRF + 限流（写接口三件套） |
| 影像精选确认 / 删除审核 | 同上，`outreach` 权限 |

- 所有写操作都记**审计日志**（控制台 →「系统设置 → 操作记录」可查）。
- 限流：宣传展示导入 60 次/小时；展示墙读取 120–240 次/小时。
