# 管理端板块与内容组织

管理端按以下顺序组织主导航；桌面侧栏、手机「全部模块」、命令搜索与面包屑共用 `public/app/console/navigation.js`。入口按现有权限显示，不增加账号权限。

| 板块 | 页面 | 主要内容 | 权限 |
| --- | --- | --- | --- |
| 总览 | `/console/overview` | 待办队列、运营概况、业务快捷入口、最近操作 | 管理端访问；业务区域按对应权限显示 |
| 管理员中心 | `/console/admin` | 我的账号、工作区偏好、系统状态、操作记录、数据维护入口 | 管理端访问；状态及记录需 settings，数据维护需 data |
| 活动管理 | `/console/events` | 活动流程与服务记录核对两个工作视图 | events |
| 宣传管理 | `/console/outreach` | 投稿审核、排期与发布登记 | outreach |
| 内建管理 | `/console/community` | 参与人员、投稿审核、生日祝福库、匹配预览、举报处理 | community |
| 物资管理 | `/console/materials` | 借用审批、库存、出库归还与流水 | materials |
| 红会留言墙 | `/console/messages` | 留言草稿、发布、编辑与下架 | community |

## 旧链接兼容

活动工作区先读取 `/api/volunteer/workflow/catalog` 的精简目录，不带报名、时长明细和通知正文；选中对象后读取 `/events/:id/detail`，按明确的项目/班次 ID 查询报名与时长。普通项目按 `ordinary.groupId` 关联，献血车沿用自然月归集，不按名称合并。源表目录仅进入「待配置」或打开源表深链接时读取，参与者资料仅进入名单时加载；新建表单只读取负责人目录。

浏览器目录缓存为会话内 30 秒，手动刷新、写入和会话切换使其失效；其他展示读保留原短期缓存。迟到的详情响应不得覆盖当前选择。活动定义与献血车排班仍需要完整读取，当前不是服务端目录分页；审批、报名、签到和时长写入仍走原有权威读取及校验流程，不使用展示快照代替门禁。原全量接口保留供兼容调用。

活动报名原生列、底表直接维护、分类/地区继承、关联与时长审核边界见 [网站活动报名总表契约](REGISTRATION_TABLE.md)。类别下拉沿用共享原生组件；地区与类别独立筛选。

- `/console/settings` 跳转管理员中心的系统状态视图。没有 settings 权限的管理员无法通过旧地址进入该视图。
- `/console/data` 保留数据维护功能，导航归属管理员中心。
- `/console/volunteers` 和 `/console/workflow` 保留原功能，导航归属活动管理。
- 生日祝福自动发送、参与规则和现有数据表保持原逻辑。

## 红会留言墙存储

留言墙使用管理平台业务 Base 中独立的「红会留言墙」表，不使用生日投稿池，也不插入演示内容。

字段均为 text：留言ID、内容、署名、来源、状态、创建人、创建时间、更新人、更新时间。

- 状态：草稿、已发布、已下架。下架保留原记录；编辑保存为草稿，确认后重新发布。
- 内容最多 1000 字，署名必填且最多 80 字，来源选填且最多 200 字。
- `/api/community/messages` 保留登录、community 权限和写操作 CSRF 校验；记录创建与修改审计。普通访客不能读取留言管理数据。
- 发布范围是管理端留言墙，未增加用户端公开展示或邮件群发。
- 表未配置时明确提示并禁止保存；不把接口故障当成空数据。

生产表迁移与应用部署分开执行。维护人使用服务器现有 `.env` 运行 `scripts/apply-message-schema.mjs` 先只读检查，再使用 `--apply --confirm=CREATE-MESSAGE-WALL` 创建空表。脚本核对生产业务 Base UUID；已有完整表不会重复创建，已有不完整表会停止，不自动覆盖字段。

界面与代码已统一为「留言」；SeaTable 物理表名与列名由数据侧单独改名，改名前后应用行为一致。

## 界面调整依据

| 调整前 | 调整后 | 原因 |
| --- | --- | --- |
| 设置、数据维护和账号入口分散 | 收纳至管理员中心 | 减少主导航层级，区分个人设置与业务工作 |
| 活动和服务记录分别占用主入口 | 活动管理内的两个工作视图 | 保留业务流程，同时统一归属 |
| 桌面、手机和面包屑分别定义页面归属 | 共用七个板块映射，保留旧链接 | 避免名称和选中状态不一致 |
| 总览请求无权限业务接口 | 按权限展示并加载业务区域 | 减少无权限错误，继续由后端拒绝越权请求 |
| 寄语没有独立维护入口 | 独立留言墙及存储 | 避免混入生日祝福数据与发送流程 |

界面沿用已有字体、主题、间距、按钮和抽屉组件；手机导航保留常用模块与全部模块入口，新区域单列呈现，交互支持减少动态效果偏好。
