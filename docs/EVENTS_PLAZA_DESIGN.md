# 活动广场参考图实现

正式页面为 `/events`；独立效果案例为 `/design/events-plaza.html`。
案例使用内存中的六条演示活动，筛选和轮播均可交互，不访问业务 API，不提交报名。
两者共享轮播、类别入口、流程组件及活动卡片。

筛选按搜索、类别、状态、地区排列；校区筛选与时间排序并列在近期活动标题右侧。
两个控件复用活动状态的下拉组件，统一箭头、浮层、选中态及键盘操作；活动时间排序支持正反序。
卡片将日期和地点置于标题下，说明位于中部，服务时长与报名按钮位于底部。
有真实已确认人数和容量时显示人数比例；无相关字段时保留原有名额信息。
未提供服务时长时显示场次信息，不用起止时间推算业务时长。
活动页的导航和紧凑页脚仅在该页面生效，其他广场保持原有外壳样式。

字体：大标题用 Noto Serif SC，正文和卡片用 Noto Sans SC；完整可变字体分包
分别覆盖 30,928 和 30,890 个 Unicode 字符，来源、校验值和大小见
`public/assets/fonts/plaza-manifest.json`。许可证沿用同目录中的 SIL OFL 文件。
字体只从本站加载，完整覆盖由互不重叠的 `unicode-range` 分包保留。页面优先加载
黑体、宋体、行书的首屏用字文件，动态内容中出现的其他字形再请求对应分包。
原先约 21 MB 的完整字体不再作为首屏下载资源。
当前固定首屏包合计 496,640 字节，约 497 KB。案例页冷缓存限速测试下载量相同；
真实活动文字若包含首屏包以外的字，会额外加载对应分包。
顶部会名与页脚会名使用志莽行书（Zhi Mang Xing）完整字库，覆盖 7,015 个字符；
来源与校验值同样记录在字体清单中，许可证为 `ZhiMangXing-OFL.txt`。
会名下面的英文为 `Red Cross Society of Nanjing University`。

使用 `font-display: optional` 避免长时间下载完成后突然替换已显示的文字。
正常连接通过预加载首屏包保留指定字体；极慢或失败的连接先稳定使用本地替代字体，
本次页面不再中途换字形。字体缓存就绪后，后续页面可使用指定字体。
本地替代字体按源字体的上升部、下降部和行隙匹配，中文全角字保持 100% 尺寸。
活动页的字体角色变量在外壳出现前设置，避免先使用旧字体再切换；案例页为加载内容
预留空间，避免脚本执行时页脚从首屏中突然移走。

重新生成：安装 fonttools 和 brotli 后，运行 `python scripts/build-plaza-fonts.py`。
源文件在 `.cache/plaza-font-sources` 缓存；缺少缓存时下载并校验上游 TTF 的 SHA256。
分包清单记录字形数、可变字重轴、Unicode 区间和文件 SHA256；生成时检查覆盖无遗漏、
分包无重叠且字重轴未丢失。稳定分包可以复用未改动的文件。

六类图标沿用当前分支的 `activityEmblem()` 与现有图标素材，不另行生成。
活动广场中，主席团专项和生命中心分别覆盖为接近参考图的三人星形图标与纯十字急救箱；
两者以 Tabler 的 MIT 图标为基础调整，来源和许可证见 `public/assets/activity-icons/README.md`。
图标的遮罩保留在内层，外层通过 SVG 轮廓膨胀滤镜加粗，避免滤镜作用在
遮罩底色而无法加粗实际线条。六类入口减少上下留白并加重、放大标题。
“我的报名”保留原人物轮廓，改为填充式显示。
轮播支持上一张、下一张、圆点、方向键和暂停，鼠标停留、键盘焦点期间停止自动切换；
只有右侧照片参与轮播，左侧标题、理念和说明固定为“把善意，化作行动”版本。
系统减少动态效果偏好会停用自动播放。切换路由时清理定时器。

轮播照片尚待 Owner 提供，当前明确显示占位。收到后只需修改
`public/app/portal/events-showcase.js` 的 `EVENT_SLIDES`，填写照片 URL 与替代文本。
生产照片放独立照片存储，不提交进源码仓库。

本地验证：分别以端口 3137 启动 `scripts/preview-site.mjs`，以端口 3138 启动
`scripts/preview-workflow.mjs`；运行 `node scripts/verify-events-plaza.mjs`。
脚本通过本机 Edge 检查桌面、手机案例交互和正式活动页的合成数据展示，截图保存在 reports。
字体专项验证为 `node scripts/verify-plaza-font-loading.mjs`，默认使用端口 3140/3141；
支持 `PLAZA_PREVIEW_URL` 和 `PLAZA_WORKFLOW_URL`。报告保存在 `reports/plaza-fonts-after.json`。
