# 活动管理与公开展示恢复（2026-10-26）

旧文件树回流使已批准活动的联系人字段参与了旧版审批摘要，造成有效记录被公开目录过滤；同时丢失了角色配置入口、活动联系人、负责人协作者、来源活动状态及相关操作。

本次以 a778915 的活动子系统为恢复参考，保留当前 main 的状态筛选、时间精度、关闭活动展示、身份并发查询及展示缓存失效机制。只恢复活动相关代码与必要依赖，不整体回退 main。

## 数据与权限边界

- 保留现有角色 JSON 的 assignments、managedAccountIds、版本和地区范围；部署不重建、不覆盖配置。
- 角色编辑接口仍以实时账号的已验证、启用 super_admin 身份授权，保存需版本匹配；普通管理员只能查看获准的信息，所有业务写入仍单独检查活动权限。
- 展示时身份源异常不再把账号既有的活动模块权限移除；来源异常不会授予新的业务写权限。
- 恢复 registrationContact 的摘要兼容，不批量改写批准摘要或重新发布活动。活动正常内容变更、过期批准版本和归档状态仍被拒绝。
- 重新读取已有来源报名关闭与结束决策。恢复排班管理接口，但本轮不新增后台自动生成排班任务。
- 生产数据库迁移、重开报名、修改活动状态与发送测试通知都不属于本次部署。

## 验证

完整 verify、ESM 具名导入、Python 发布/回滚测试，以及桌面/手机的角色编辑、地区权限、只读活动、联系人、请假处理、项目人员、状态筛选和时间精度回归。浏览器预览使用合成账号与内存数据，不连接生产身份库、业务表或 SMTP。

上线需另外检查最终 main 的 CI 和部署、release.json、运行文件哈希、公开目录中的新版献血周/会员大会，以及现有权限配置版本和哈希。会员大会若报名截止已过，恢复展示不代表重开报名。
