## 本轮发现与修正

1. 页脚版权小字在青竹绿、鸢尾紫、秋日金底材上对比度为 4.22 / 4.41 / 3.98；改用页脚所有者 `portal.css` 中的 secondary 文字。
2. 周末表头原固定灰色在五主题均低于 4.5；由 `calendar.css` 使用主题 secondary。业务状态色保持固定。
3. 登录后的早安晚安表单在绿色/金色主题的小字不足 4.5；在 `themes.css` 调整 muted 的混色比例，保持次级层级。
4. 提示浮层原无关联说明、无法移入阅读或 Escape 关闭；共享 primitives 补充 aria-describedby、悬停容错、键盘关闭，主题按钮复用相同组件。
5. 抽屉/底部面板入场由 380ms 收至 280ms，按钮按压使用 90ms；原 reduced-motion 保留。
6. 删除 refinement 中日历 hover/transition/数字重复所有权；周历归 calendar，报名详情归 booking。修正记录空态选择器，并收紧会员记录空态，避免小数据占据长页。

7. 125% 布局缩放截图暴露活动分类按钮文字挤压，虽未造成整页溢出仍影响阅读。筛选区改用内容宽度的 container query 决定双列/单列，测试补充按钮文字边界检查。

## 验证边界

自动扫描不等同于完整人工 WCAG 认证；本轮无屏幕阅读器实机、Safari/Firefox 或操作系统原生 125% 浏览器缩放验收。1.25 倍 CSS 布局缩放验证重排与溢出，不能替代浏览器原生缩放。会员、名片、普通活动与报名使用合成账号/数据；线上仅执行公开页面读取，未提交真实业务记录。布局矩阵审查与详细交互测试分别记录，不将每张截图等同于完整业务流程验收。

## 美术取舍

保持前三轮场景层次与五套色彩方向；本轮提高可读性、收紧空态、统一反馈，不再添加新的装饰或渐变层。较深的小字是满足可读性的必要调整。圆角使用既有 token 梯度，主题个性仍保留。
