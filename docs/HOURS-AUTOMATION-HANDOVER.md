# 时长汇总与个人主页的写入边界

终审通过并归档后，网站保留以下两处写入：

- 活动及时长汇总表：按姓名＋学号匹配，以服务时长差额累计，保留历史数据。
- 网站志愿时长汇总表：按现有账号及身份校验重算服务、培训、交通汇总。

个人主页（编辑版）及网站个人主页表的时长不再由网站入账任务写入。
NJUTable 自动化负责后续传递；网站个人主页的总时长、学年时长直接读取个人主页数据，不叠加本站待处理记录。
网站不再承诺周一 06:00 更新，不提供直接写个人主页或改学年基数的入口。
旧客户端携带 profiles 参数仅触发汇总表核对，不会恢复个人主页写入。

## 兼容与核对

- 原入账回执、写入前后快照、已确认修订历史保留，已完成的两表写入不会因切换重复累计。
- 不回放旧的个人主页待确认写入，不据旧回执宣称个人主页已更新。
- 本次不修改 NJUTable 设置、自动化、公式或生产数据，亦不自动回退此前写入的时长。
- 旧个人主页已写数据应结合 NJUTable 修改历史与入账回执人工核对。不能仅按当前总数推算某场活动是否重复。
- 页面显示“已写入汇总表”只证明网站两表回读成功；个人主页是否更新以读取的实际总数为准。
